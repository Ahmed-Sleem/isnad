# Evaluation protocol and current baseline

## Reproduce

From the repository root, with the project environment installed:

```bash
python scripts/evaluate_synthetic.py \
  --output evaluation/reports/isnad-synthetic-baseline-2026-10-05.json
```

The report records the seed, the exact 200 sampled references, source ID/version/hash, case counts, raw counts, metrics, and limitations. Unique normalized ayahs are ranked by SHA-256 of `seed:reference`, making the selected sample independent of Python's random-sampling implementation. The script uses Python's standard library and the pinned Tanzil Uthmani v1.1 corpus; it makes no external model or API calls.

## Current synthetic baseline

Report: [`evaluation/reports/isnad-synthetic-baseline-2026-10-05.json`](../evaluation/reports/isnad-synthetic-baseline-2026-10-05.json)

| Measurement | Cases | Result | Target | Scope |
|---|---:|---:|---:|---|
| Explicit streaming-marker precision / recall / F1 | 200 (100 marked, 100 plain) | 1.00 / 1.00 / 1.00 | F1 ≥ 0.85 | Reserved marker recognition only; not free-form citation extraction |
| Textual-verification precision | 200 (100 exact source ayahs, 100 unrelated strings) | 1.00 (100 TP, 0 FP) | ≥ 0.90 | Clean Arabic text from the same source used by the verifier |
| Wrong-reference ayah correction accuracy | 200 full ayahs with an adjacent incorrect locator | 0.995 (199/200) | ≥ 0.95 | Unique normalized ayah strings sampled deterministically from the pinned edition |

## Interpretation and limitations

These are **controlled synthetic baselines**, not independent validation of the original product targets. The text examples are generated from the same Tanzil corpus as the verifier; negatives are obviously unrelated strings; labels are generated by the test harness rather than independently annotated; and the correction task checks exact full-ayah location under a deliberately wrong reference. One of 200 correction cases remained ambiguous and is counted as incorrect.

The stream implementation recognizes the reserved `[[ISNAD-CITATION ...]]` protocol. It does not detect arbitrary Qur'an or hadith references in unconstrained prose. Therefore, the natural-language citation-detection F1 target remains **unproven and is not measured by the marker score**. Verification precision on noisy paraphrases, partial quotes, source disagreements, and human-authored examples also remains unproven. Do not present these baseline values as production guarantees.

## Next evaluation gate

Before describing performance as validated, create an independently annotated, versioned set covering Arabic and English, Qur'an and HadeethEnc, paraphrases, partial wording, wrong references, repeated ayahs, ordinary numeric prose, malformed/incomplete stream delimiters, adversarial quote contents, and source outages. Split development and held-out cases; report per-source/per-language precision and recall, confusion counts, confidence intervals where appropriate, and exact corpus/API versions. Preserve the human labels and evaluation code with the report. Do not count source outages as not-found results or hadith grading as text matching.
